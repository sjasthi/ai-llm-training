# AI Development Frameworks

This guide introduces popular AI development frameworks grouped by
purpose.

## 1. Agent Frameworks

  Framework               Best For                        Language
  ----------------------- ------------------------------- --------------------
  LangChain               General-purpose agents          Python, JavaScript
  LangGraph               Stateful production workflows   Python, JavaScript
  Microsoft AutoGen       Multi-agent systems             Python
  CrewAI                  Role-based AI teams             Python
  Google ADK              Gemini-based agents             Python
  OpenAI Agents SDK       OpenAI-native agents            Python
  Amazon Strands Agents   AWS agents                      Python

## Recommended Learning Path

1.  Learn Python and FastAPI.
2.  Learn Prompt Engineering.
3.  Build simple applications with LangChain.
4.  Learn LangGraph for production workflows.
5.  Learn RAG using LlamaIndex.
6.  Explore OpenAI Agents SDK.
7.  Learn MCP.
8.  Experiment with multi-agent systems using AutoGen or CrewAI.
